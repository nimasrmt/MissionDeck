# Contributing

Open an issue describing a bounded change, create a feature or fix branch from the appropriate base, and keep file ownership clear when collaborating with other agents. Run `python -m pytest -q`, report exactly which tests were offline, and open a reviewed pull request. Live Orca tests require an explicitly authorized local environment. No inference is required in CI. Do not commit private artifacts or claim unsupported functionality. See AGENTS.md and CONTRACT.md.
